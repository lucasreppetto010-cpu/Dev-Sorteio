# 🎲 Sorteio de Números
Um **gerador de sorteio de números** simples, rápido e interativo desenvolvido com tecnologias web modernas. A aplicação permite sortear números aleatórios dentro de um intervalo definido pelo usuário, com uma interface intuitiva e visual atrativa.

Perfeito para gincanas, rifas, sorteios, jogos, competições e qualquer situação onde você precise gerar números aleatórios de forma justa e transparente.


![Conversor de Moedas](./assets/readme.png)

## ✨ Características Principais

- 📱 **Responsive** - Para utilizar em Tablet, Celulares e Desktop
- 🎯 **Sorteio Aleatório** - Gera números completamente aleatórios
- 📊 **Intervalo Personalizável** - Escolha o número inicial e final
- 🎨 **Interface Atrativa** - Design limpo e moderno
- ⚡ **Resultado Instantâneo** - Sorteio realizado em tempo real

  

## 🚀 Tecnologias Utilizadas

| Tecnologia | Descrição |
|-----------|-----------|
